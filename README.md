# אקדמיית שור

קורס מקוון בעברית (RTL) על מתמטיקת סיכון, מאת משה קריסטל.

הקו המנחה: המפסיד הטוב ביותר מנצח. לומדים איך להפסיד נכון לפני שלומדים איך להרוויח.

התכנים לימודיים בלבד. אין כאן ייעוץ השקעות, אין איתותים, ואין הבטחת תשואה.

החבילה הזו היא המוצר המלא: שבעה מודולים עם שיעורים ומבחן, מעבדת מחשבונים, ויומן משמעת. אין שלד. מודול נפתח רק אחרי ציון של 70% במבחן של הקודם.

## מה צריך

- Node.js 20.9 ומעלה
- npm

אין בסיס נתונים חיצוני. הנתונים נשמרים בקובץ SQLite מקומי.

## התקנה

מתוך תיקיית הפרויקט, אחרי פתיחת ה-zip:

```bash
cp .env.example .env
npm i
npx prisma migrate deploy
```

`npm i` מריץ `prisma generate`. מעתיקים את `.env` לפני ההתקנה, כי Prisma קורא את `DATABASE_URL`.

לפני הרצה אמיתית מחליפים את `AUTH_SECRET` במחרוזת ארוכה ואקראית. הערך בקובץ הדוגמה מיועד רק לפיתוח מקומי.

## הרצה

```bash
npm run dev
```

האתר עולה בכתובת [http://127.0.0.1:43123](http://127.0.0.1:43123).

בנייה והרצה של גרסת הייצור:

```bash
npm run build
npm start
```

גם `npm start` מאזין על פורט 43123.

## בדיקות

```bash
npm test
```

הבדיקות מכסות את נוסחאות המעבדה (גודל פוזיציה, תוחלת, התאוששות, יחס סיכון–סיכוי, רצף הפסדים) ואת שרשרת הפתיחה של המודולים. סף המעבר הוא 70%.

## ברירות מחדל לסיכון

| כלל | ערך |
| --- | --- |
| סיכון לעסקה | 0.3% מההון (`0.003`) |
| Heat מקסימלי | 1.5% סיכון פתוח (`0.015`) |

אלה כללי עבודה ללימוד. הם לא תחזית ולא יעד תשואה. המחשבון מזהיר כשחורגים מהם.

## מפת המודולים

21 שיעורים. 7 מבחנים, 4 שאלות בכל מבחן. כל השיעורים בסטטוס מלא.

| מודול | שם | שיעורים | מבחן |
| --- | --- | --- | --- |
| 1 | ללמוד להפסיד נכון | 3 | 4 שאלות |
| 2 | שפת ה-R | 3 | 4 שאלות |
| 3 | תוחלת | 3 | 4 שאלות |
| 4 | דרוודאון והתאוששות | 3 | 4 שאלות |
| 5 | גודל פוזיציה | 3 | 4 שאלות |

שיעורי מודול 1: ההפסד הוא חלק מהתהליך. סטופ הוא אסטרטגיה, לא כישלון. אין נקמה, ויש מפסק.

שיעורי מודול 2: מה זה 1R. למה אחוזים מטעים. למדוד עסקה ב-R.

שיעורי מודול 3: נוסחת התוחלת. למה אחוז הצלחה נמוך יכול לנצח. תרגול: תוחלת על סדרה כתובה. מחשבון: תוחלת.

שיעורי מודול 4: מהו דרוודאון. טבלת ההתאוששות. למה הגדלת סיכון אחרי הפסד הורסת. מחשבון: התאוששות.

שיעורי מודול 5: סיכון בכסף חלקי מרחק הסטופ. 0.3% לעסקה ו-Heat של 1.5%. עדכון חודשי של ההון. מחשבון: גודל פוזיציה.

שיעורי מודול 6: איך להשתמש במחשבונים. סימולטור קצר של רצף. שמירת תוצאות. מחשבונים: רצף הפסדים ותוחלת, וקישור למעבדה.

שיעורי מודול 7: תבנית היומן. כרטיס יומי. טרייד שלא תועד — לא קיים. קישור ליומן.

## הרשמה וכניסה

1. דף הבית והעמוד «אודות» פתוחים בלי חשבון.
2. הרשמה בכתובת `/register`: שם, אימייל, סיסמה של 8 תווים לפחות, ואימות סיסמה. אין ספק התחברות חיצוני.
3. אחרי הרשמה נפתחת עוגיית התחברות והלוח ב-`/app`.
4. כניסה חוזרת ב-`/login` עם אימייל וסיסמה.
5. בלי התחברות, כל נתיב תחת `/app` מופנה לכניסה.
6. מודול 1 פתוח מיד. השיעורים בתוך מודול נפתחים לפי הסדר. המבחן נפתח אחרי שכל שיעורי המודול סומנו כהושלמו.
7. ציון של 70% ומעלה פותח את המודול הבא. ציון נמוך יותר משאיר אותו נעול. נשמר הציון הגבוה.

יציאה מהחשבון נמצאת בעמוד החשבון.

## מעבדה ויומן

המעבדה ב-`/app/lab`: גודל פוזיציה, יחס סיכון–סיכוי, תוחלת, התאוששות מדרוודאון, רצף הפסדים. כל מחשבון שומר את התוצאה האחרונה של אותו כלי.

היומן ב-`/app/journal`: תאריך, טיקר, R מתוכנן, R בפועל, הערות, ותגיות משמעת (סטופ, גודל, בלי נקמה, תיעוד, רמזור).

## משתני סביבה

| משתנה | משמעות |
| --- | --- |
| `DATABASE_URL` | ברירת מחדל `file:./dev.db`. קובץ SQLite נוצר בתיקיית `prisma` |
| `AUTH_SECRET` | מפתח לחתימת עוגיית ההתחברות. להחליף בסביבה אמיתית |

## בסיס נתונים

SQLite דרך Prisma. המיגרציה הראשונה נמצאת ב-`prisma/migrations`.

`npx prisma migrate deploy` יוצר את הטבלאות על קובץ מקומי חדש. אין צורך לייבא נתונים.

כדי לעבור ל-Postgres משנים את `provider` ב-`prisma/schema.prisma` ואת `DATABASE_URL`, ויוצרים מיגרציה חדשה.

## פריסה ל-Railway

ה-repo מוכן לפריסה עם `Dockerfile` + `railway.json` (בונה Dockerfile, healthcheck על `/`, הפעלה מחדש על כשל, volume ב-`/data`).

1. ב-Railway: פרויקט חדש ← Deploy from GitHub repo ← בחר את ה-repo.
2. ב-Service ← Settings ← Volumes ← Add Volume, mount path: `/data` (חובה — אחרת הנתונים יימחקו בכל redeploy).
3. ב-Service ← Variables הגדר:

| משתנה | חובה | ערך |
| --- | --- | --- |
| `AUTH_SECRET` | כן | מחרוזת אקראית ארוכה, למשל פלט של `openssl rand -base64 48`. בלעדיו השרת מסרב לעלות בייצור |
| `DATABASE_URL` | לא | ברירת מחדל: `file:/data/dev.db` (על ה-volume). לשנות רק אם צריך נתיב אחר |

`PORT` מסופק אוטומטית ע"י Railway. ב-startup רצות המיגרציות (`prisma migrate deploy`) ואז `next start`.
